PERSONAL SALES INTELLIGENCE SYSTEM — VERSION 1 PWA

WHY THIS PACKAGE:
The downloaded HTML file opened with a content:// URL. Chrome may not retain localStorage consistently for downloaded files. This package is intended to run from a stable HTTPS website origin.

FILES:
- index.html: the app
- manifest.webmanifest: installable app metadata
- sw.js: offline app-shell cache
- icon.svg: app icon

DEPLOYMENT OVERVIEW:
1. Create a GitHub repository. Do not put customer data in the repository.
2. Upload all four files to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.
5. Wait for GitHub Pages to provide the HTTPS site URL.
6. Open that HTTPS URL in Chrome on your Android phone while online once.
7. Add a fictional lead, close the tab, reopen the same HTTPS URL and confirm the lead remains.
8. In Chrome's menu, choose Add to Home screen or Install app if available.
9. Once cached, test airplane mode. The app shell should open offline.

LIMITATIONS / SAFETY:
- First visit requires internet to cache the app.
- Data remains in the same browser profile on the same device; no cross-device sync.
- Local browser storage is not encrypted by this app and may be cleared by device/browser settings. Export backups regularly.
- Do not enter real customer information until Platinum Credit approves the tool and its data handling.
- Never store PINs, passwords, or unnecessary sensitive details.
- This is not an official Platinum Credit system and does not decide loan eligibility.
